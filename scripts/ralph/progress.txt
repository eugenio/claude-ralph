## Codebase Patterns
- Ralph function definitions in PowerShell profile follow pattern: `function ralph-xxx { pwsh "$path/ralph-xxx.ps1" @args }`
- Profile parsing should handle both Unix (\n) and Windows (\r\n) line endings using `$content -split "\`r?\`n"`
- Tests in scripts/ralph/tests/ use Pester 5.x with BeforeAll blocks for test setup
- When comparing profile functions, use Get-ExpectedRalphFunctions, Get-ProfileRalphFunctions, Compare-RalphFunctions
