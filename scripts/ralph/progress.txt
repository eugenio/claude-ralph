- Profile parsing should handle both Unix (\n) and Windows (\r\n) line endings using `$content -split "\`r?\`n"`
- Tests in scripts/ralph/tests/ use Pester 5.x with BeforeAll blocks for test setup

- Pass script-level parameters to Main function using splatting syntax: `Main -Force:$Force -Check:$Check -SkipAliases:$SkipAliases`
- Bash function parsing: Use pipe `|` as delimiter for multi-value output instead of quoted strings (read doesn't parse quotes)
- When bash functions need to return values and set arrays, call populate function directly (not in subshell) to preserve array values
