## Codebase Patterns
- Use `eval "$(get_ralph_paths)"` to load path variables in bash scripts
- jq is required for JSON parsing in bash scripts
- Shellcheck directives must be on separate lines before the command, not as trailing comments
- Multi-character Unicode progress bars require careful loop construction (avoid `seq` with printf format strings)
- Use atomic directory creation `mkdir` for lock acquisition (fails if dir exists)
- Store heartbeat timestamps as Unix epoch for cross-language compatibility
- Use flock for file-level locking when available
